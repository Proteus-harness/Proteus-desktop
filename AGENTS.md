# Proteus Desktop

Клиент на GPUI находится в `src/`. Он общается с Core через публичный HTTP/SSE API
и использует типы из `proteus-contracts`. Ревизии Core, модулей и расширений для
поставки закреплены в [repositories.json](repositories.json).

## Интерфейс и расширения

Клиент отвечает за нативные виджеты, фокус, клавиатуру и состояние сессии.
Поведение конкретного расширения живёт в его пакете. Изменения публичной схемы
проводите одновременно в клиенте и затронутых расширениях.
Границы описаны в [руководстве по расширениям](docs/extensions.md).

Для панелей, меню, вкладок и редактора ориентируйтесь на поведение Zed
и используйте общие примитивы Proteus. Правила взаимодействия и оформления
собраны в [DESIGN.md](DESIGN.md). При переносе кода из Zed укажите исходный
файл. Для `client-common` (Apache-2.0) подходит только код из Apache-крейтов Zed.
Лицензии остальных крейтов указаны в [README](README.md#лицензия).

## Проверка и поставка

Для локальной правки выберите нужный тест в [руководстве по сборке](BUILDING.md#запуск-и-проверки).
Изменение интерфейса проверьте в нативном окне на синтетическом чате.
После изменения протокола проверьте обмен клиента с расширением.
Для замеров используйте одинаковые входные данные и укажите состояние кэша.
См. [корпуса и измерения](BUILDING.md#корпуса-и-измерения) и [расход ОЗУ](https://github.com/Proteus-harness/Proteus-core/blob/main/docs/development/memory.md).

Проверенную правку приложения оформляйте отдельным коммитом и обновляйте
затронутые [компоненты рабочей поставки](BUILDING.md#выбор-компонентов).
GitHub Actions запускаются вручную и по релизным тегам `v*`.
Секреты и реальные сессии не публикуйте.
