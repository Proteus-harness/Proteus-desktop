# Перенос оптимизаций dot #78–#80 — 2026-11-03

Перенесены три ограниченных изменения, уменьшающие лишнее копирование и подготовку скрытого UI. Это подтверждение реализации и регрессионных проверок; снижение общего RSS/PSS и ускорение работы пока не измерены.

## Что изменилось

| Источник и локальный commit | Было → последствие → исправление |
|---|---|
| [#78](https://github.com/Qweasd123tg/proteus-modules-dot/pull/78), Core `9305c2b73f73cc96b1f96c648bec2712e9697565` | Карточка тула субагента сначала копировала весь результат, затем обрезала `String`. Длина уменьшалась, но capacity большой копии оставалась. Теперь сначала выбирается заимствованный UTF-8-префикс, затем копируется только он. Полный результат в канонической истории сохраняется. |
| [#79](https://github.com/Qweasd123tg/proteus-modules-dot/pull/79), Modules `dff86111b74f833da62b9fceb378149855f4910f` | Завершение Responses глубоко клонировало уже принадлежащие адаптеру JSON `response/output` и восстановленные streamed items. Теперь эти значения перемещаются через `take`/move. Borrowed fallback по-прежнему требует копирования; итоговые данные, порядок, metadata и usage сохраняют прежнее поведение. |
| [#80](https://github.com/Qweasd123tg/proteus-modules-dot/pull/80), Desktop `fec498bcbd8e713f200cf1b6acfb7ac0eeb7ee42` | Свёрнутый tool output заранее готовил расширенный текст и его дерево элементов. Общий `preview_reveal` теперь принимает немедленно потребляемый builder: в покое закрытый блок не строит расширенную ветку; при раскрытии, закрытии и развороте анимации строит её. Исходный текст и вычисление превью остаются; постоянный кэш не добавлен. |

#78 и #79 взяты из upstream `450238e59688980180b22154706e1543f24c84df`; #80 — из draft PR, ревизия `9616d3b3bfb3d01d4b7d9daffcf9c040cdf9272d`. Статус draft не заменяет локальную проверку. Публичные контракты Core и формат истории этим переносом не меняются.

В #80 вызов из `tool_row` откладывает `clip_block` полного результата и построение
его subtree. Остальные call sites адаптированы к builder API; часть textarea
по-прежнему готовит editor заранее. Оптимизация всех скрытых редакторов не заявляется.

## Сборка и готовая поставка

Обычный release, `CARGO_BUILD_JOBS=2`, компоненты `desktop core modules`;
расширения взяты из готовой поставки. Cargo/OS caches сохранены. Это сборка
изменений с готовыми зависимостями, не холодная сборка и не сравнение с прежней
версией. Часть первого прохода пересекалась с функциональной проверкой GUI.

Повтор: **0,81 / 0,23 / 0,23 с** соответственно; остальное — запуск и упаковка.
Максимальный RSS одного процесса не является пиком всего дерева и не складывается
с PSS. Sampled peak может пропустить короткие пики; это память сборки, не приложения.

Supervisor первого замера завершился с 143; дочерний build продолжился и записал
полный лог, GNU time и финальный `Portable:`. Поэтому первый `samples.jsonl`
не используется для оценки пика памяти, а exit code самого portable не восстановлен.
Повторный запуск завершился с **0**. Исходные результаты сохранены без перезаписи:
`build-cost/`, `build-cost-recovered.json`, `build-cost-repeat/` в каталоге evidence.

## Native-проверка #80

Использован существующий `native-stream/code_blocks.py --tool-previews` в
изолированном background-gui сеансе. Core, модели, настоящие чаты и команды tools
не запускались. Начальная debug-проверка дополнялась проверкой release Native;
SHA256 проверенного release ELF совпал с Native в готовой portable-папке:
`eb4f084669ab5b5f03af60a367e1c5a06d50774b742c00fb862a302f5dd161b4`.

Проверены раскрытие, сворачивание и повторное раскрытие subject из 24 строк
и result из 80 строк. После перехода к концу видны строка 80 и отдельный
assistant-маркер; углы на проверенных endpoints и fade превью сохранены.
Copy в свёрнутом состоянии возвращает полный source, побайтно:

| Поле | UTF-8 bytes | SHA256 |
|---|---:|---|
| subject | 887 | `2d6684f1aa6f40fe853d6e1749da6ae2c61bd6bc0434cc7d27ebb5682a13fc92` |
| result | 3840 | `17c355d82b3821e9dcfb74d80c9d8de78604ce69eecf17bf385070c2f7d2364c` |

Кадры получены постоянным `capture_motion.py`, без изменения production-анимации.
Helper может пропустить промежуточные кадры; непрерывность каждого кадра и быстрый
разворот в native capture не подтверждаются. Разворот проверен unit regression.
Функциональная проверка выполнялась одновременно со сборкой и не является замером
latency, FPS или RSS/PSS. GUI-сеанс и все его процессы остановлены.

Локальный evidence: `build/verification/dot-78-80-20261102/` — тестовые логи,
`ready-before.json`, `ready-after.json`, `artifact-checks.json`, build-cost reports;
`native-release/` — state, checks, исходные fixtures, результаты Copy и кадры.
