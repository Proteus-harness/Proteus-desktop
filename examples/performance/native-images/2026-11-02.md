# Миниатюры отправленных изображений: 2026-11-02

На одном синтетическом чате из 16 PNG PSS готового Native после загрузки
снизился с 384,67 до 228,30 МиБ (−40,65%). Это результат данного сценария,
не оценка всей памяти Proteus или доказательство отсутствия других утечек.

## Изменение

Раньше рамка 96 px ограничивала только геометрию. UI сохранял encoded
оригиналы, а неявный GPUI asset cache — полноразмерные декодированные кадры.
Удаление ссылок из чата само по себе не очищало этот cache и atlas.

Теперь оригинал превращается в ограниченную миниатюру до публикации в UI.
Все чаты делят LRU и два слота на HTTP/decode/принятие результата. Строки и
retained Img держат Weak lifetime token: вытесненный bitmap нельзя повторно
загрузить после отложенного atlas cleanup. Заполненная очередь ждёт места;
устаревший результат не заменяет новый запрос. GIF/WebP сохраняют кадры и
задержки в пределах явных лимитов. Бюджеты и ограничения описаны в [README](README.md#границы-миниатюр).

Использован уже присутствовавший `image 0.25.10`; новых пакетов или версий
в lockfile нет. PNG/JPEG/WebP/GIF decode, EXIF и animation disposal выполняет
библиотека. Обрезка до resize следует cover-геометрии чата; применён подход
нативной подготовки изображений из Zed `crates/language_model/src/request.rs`.

## Условия

- До: готовый release Desktop `e93aea951e6f920a2392863ddea30b2c52b76c04`,
  ELF SHA-256 `ca1c7d294c1e7371bd3f1cc24944c3522ef78fe85fb976f2dd5d9637edd04552`.
- После: чистый `d4b43c1905404470212afb64a76c3a9927e40710`,
  ELF SHA-256 `98ea67dfba55847e8295311e8d2497fa3774845a988a8dea209eb85819ce4c21`.
- Обычный release, один и тот же isolated background-gui дисплей 1440×960,
  настройки motion off, пустой каталог расширений, без Core/модели/реальных историй.
- 16 разных PNG 2048×1024, 128 МиБ decoded RGBA; SHA-256 всех PNG совпадают.
  По две картинки в сообщении, искусственная HTTP-задержка 50 мс.
- Начальное дно → верх → возврат вниз → empty snapshot → остановка.
  В обоих запусках получены все 16 ID ровно по одному разу, HTTP завершён без
  ошибок. Скриншоты подтвердили видимые пары сверху/снизу и пустой чат после
  замены; это не pixel oracle всех 16 картинок.
- Sampler ≈100 мс, дерево только Native. Observer, compositor и Python-сервер
  исключены; GPU VRAM не измерялась. Между запусками Native останавливался,
  runtime и сборка не пересекались.

Проверены равные hashes transport, launch helpers и sampler. После baseline
в runner добавлен отказ при самостоятельном выходе Native; в `fixture.py` —
проверки stream ID, монотонного seq и запрет повторной отправки initial snapshot.
Обратное удаление этих guards в памяти даёт точный baseline SHA-256
`09506ae92c22429c2bceeb7cb785143312223fac9a44d7fc94a81cbd5944d51e`;
успешный payload, corpus, HTTP image path и задержка не менялись.
Длительности запусков различаются (337/82 с), поэтому CPU totals,
latency и время старта по этой паре не сравниваются. Таблица использует
установившиеся именные samples, а не одинаковые секунды после старта.

## Результат Native

| Состояние | PSS до, МиБ | PSS после, МиБ | RSS до, МиБ | RSS после, МиБ |
|---|---:|---:|---:|---:|
| Загружены все 16 | 384,67 | 228,30 | 415,00 | 256,97 |
| Возврат вниз, без новых fetch | 384,67 | 228,36 | 415,00 | 257,02 |
| Empty snapshot, после settle | 384,67 | 226,15 | 415,00 | 254,82 |
| Одновременный sampled peak | 384,67 | 228,57 | 415,00 | 257,24 |

SwapPss — 0 в обоих запусках. Максимум одновременно активных HTTP image
requests — 6 → 2. Это наблюдение HTTP; общий fetch/decode reservation и
межвладельческий бюджет дополнительно проверены focused тестами и кодом.

После очистки resident память почти не падает и на новой версии. Удаление
владельцев CPU bitmap проверено тестами, atlas cleanup — исходниками; PSS
не разделяет allocator, renderer/driver и прочее удержание процесса.
Полное освобождение resident памяти и VRAM этим измерением не доказано.
Корпус не достигает LRU64/16MP и не проверяет десять чатов: eviction,
несколько владельцев, stale completion и очередь проверяются отдельно.

659 packages, 1942 dependency edges, включая dev/build dependencies; это не
количество заново скомпилированных crates.

`scripts/test.py`: 571 passed, 2 явно ignored, 0 failed. Focused image tests:
29 passed, из них 18 новых. Python fixture tests: 14 passed, включая
самостоятельный выход Native с кодами 0/7, control stop и SIGTERM.
Форматирование, лицензии и diff check пройдены. Независимое source review
не оставило блокирующих замечаний. GIF/WebP, EXIF, saturation и atlas lifetime
проверены focused тестами; native screenshots этого стенда проверяли PNG.
