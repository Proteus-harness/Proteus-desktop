# Нативная проверка прокрутки чата

```sh
env -u CARGO_TARGET_DIR CARGO_BUILD_JOBS=2 cargo build --release --example chat_scrolling
target/release/examples/chat_scrolling --verify build/verification/chat-scrolling.json
```

Запускайте бинарник в отдельном нативном display через `background-gui`, без
одновременного ручного ввода. Без `--verify` остаётся окно для ручной проверки.
Отчёт содержит `status`, ошибку при неудаче и геометрию каждого сценария.
Успех запуска процесса не означает успешное прохождение: проверяйте JSON.

Example импортирует настоящие `ChatScroller` / `ChatList`, wheel/middle,
scrollbar и `TailFloor` непосредственно из production. Заменены только
не относящиеся к прокрутке tooltip, кнопка перехода и анимация её появления.
История состоит из 400 резидентных строк: 24–50 px и 880 px. Предзагрузка
страниц здесь не проверяется; для неё есть `history_scrollbar` и native-history.

События колеса, средней кнопки, движения и Escape отправляются через публичный
`Window::dispatch_event` в реально отрисованном активном окне. Положение
вычисляется по фактическому `on_prepaint` строки и `visible_rows`, а не по
приблизительной высоте scrollbar. Таймеры только опрашивают результат;
они не двигают список и не принуждают его перерисовываться.

Проверяются серия из 18 событий без промежуточной раскладки (3240 px),
фактическое движение не больше 200.5 px за один layout по покадровой трассе, мёртвая
зона средней кнопки, увеличение скорости от расстояния и смена направления,
отпускание за пределами чата, остановка Escape и работоспособность обычного
колеса после Escape. После остановки сразу проверяются неподвижность и отсутствие
уведомлений самого ChatScroller. Затем, когда истекли настроенные в теме таймер
скрытия scrollbar и конечные переходы его видимости/ширины, проверяется также
отсутствие перерисовок родителя: одно скрытие ползунка не является циклом прокрутки.
Проверка не
подменяет backend/страницы, drag scrollbar или ускорение физического устройства.

Дополнительно включается настоящая плавная прокрутка production. Для обычного
хвоста и хвоста с «Думаю» новая сессия списка сначала получает естественный
конечный якорь. Сохраняется реальная `on_prepaint` геометрия последней строки
или caption, отправляется колесо на 180 px вверх, затем вызывается публичный
`ChatScroller::scroll_to_end`. Конечная координата должна совпасть с исходной
с точностью 0.5 px; простой видимости подписи недостаточно. Так проверяется
и учёт padding списка, который иначе оставлял 16 px недокрученного хвоста.
Для короткого и пустого списка переход вниз дополнительно проверяет отсутствие
фантомной прокрутки и бесконечного цикла уведомлений/перерисовок. Новые сценарии
включают motion только локально; прежние wheel/middle проверки остаются без него.
