# DCP — Прежняя Упаковка Эксперимента

Архивные packaging helper и smoke DCP. Штатная упаковка и проверки их не
импортируют и не запускают. Для возобновления потребуются явное подключение
и адаптация к `Proteus-modules/research/dcp`.

Сам плагин отложен в
[Proteus-modules/research/dcp](https://github.com/Proteus-harness/Proteus-modules/tree/main/research/dcp).
