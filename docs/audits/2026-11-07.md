## Дополнение по EOF локального терминала

Нативный smoke первоначальной сборки обнаружил потерю последнего `printf`:
Ghostty выходил по EOF, когда dirty frame ещё ожидал обычный frame credit.
Теперь граница EOF публикует финальный экран немедленно. До `Exited` actor
закрывает PTY и забирает child; он сохраняет только ограниченный VT
(8 MiB scrollback) и ждёт wake для readonly scroll/resize/base до закрытия
вкладки. Нового потока на завершение не создаётся; ввод после EOF отклоняется.
Status/restart выделены в отдельную полосу, которая не закрывает последние строки.

Terminal suite: 26 passed; новая проверка задаёт exhausted frame credit и
незакрытый synchronized-output hold, подтверждает tail, child reap,
scroll/resize/theme после EOF, отсутствие курсора/ввода и завершение actor
при Drop. Весь Desktop workspace после production-исправления повторён:
750 passed, 2 ignored, 0 failed. Дополнительное уточнение identity/timer в
regression fixture подтверждено целевым повтором. Нативный повтор release-сборки прошёл; первый неудачный screenshot сохранён
как evidence и не объявлен успешной проверкой.

Дополнительная нативная проверка обнаружила stale grid после появления footer:
видимая область уже 718 px, но кадр ещё содержал 45 строк для прежних 794 px.
`notify` во время prepaint терялся в текущем кадре. Refit теперь назначается
через `window.on_next_frame`; отдельная debug GUI проверка без пользовательского
wheel подтверждает переход на 41 строку и видимый финальный маркер.
Принудительное перемещение viewport вниз не добавлялось: backend регрессии
5→3 (с hold), 44→40 (без hold) и resize прокрученной истории прошли без него.
Временная диагностика удалена. Это исправление scheduling, а не потеря данных.
